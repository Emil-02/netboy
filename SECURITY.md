# Security Policy

`netboy` memindai jaringan secara langsung dan *read-only*. Hasil pemindaian dan banner servis diproses sepenuhnya di komputer lokal dan tidak pernah dikirimkan ke server eksternal mana pun.

## Melaporkan kerentanan

Jika kamu menemukan potensi celah keamanan atau bug sensitif pada implementasi `netboy`, mohon untuk **tidak membuka issue publik**.

Gunakan [GitHub Security Advisories](https://github.com/Emil-02/netboy/security/advisories/new) agar rincian teknis tetap bersifat privat sampai perbaikan dirilis.

## Versi yang didukung

Versi `0.1.x` menerima pembaruan berkala dan perbaikan keamanan. Disarankan untuk selalu menggunakan rilis terbaru melalui `go install` atau binary rilis resmi.
